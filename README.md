## Maple Leaf Kitchen

## Project Description

Maple Leaf Kitchen is a restaurant website that allows customers to browse meals, add items to a shopping cart, and contact the restaurant. The website provides an interactive experience using HTML, CSS, and JavaScript.


## Problem Statement

Many restaurant websites only display menus without allowing users to interact with them. This project demonstrates how JavaScript can be used to create a more engaging restaurant website with dynamic features.


## Features

- Responsive multi-page website
- Home, About, Menu and Contact pages
- Interactive shopping cart
- Add new menu items dynamically
- Contact form with validation
- Data persistence using LocalStorage
- Dynamic DOM manipulation
- Event-driven interactions
- Attractive and responsive design
